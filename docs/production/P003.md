# P003: Custom domains and shared identity

Status: future production planning gate; not part of demo implementation and not authorized execution.

## Dependencies

P001

## Work to specify

Design verified domain ownership, certificate lifecycle, trusted host routing, cross-domain login/redirect state, session isolation, logout and abuse handling. Keep branded-store origin untrusted until verified.

## Deliverables and exit criteria

Two independently owned test domains with safe shared-login flow, redirect allowlist, CSRF/session isolation and recovery tests.

## Boundary

Sharing one cookie domain is not a universal custom-domain SSO solution.

After discovery, break this gate into small implementation tasks with exact provider/API versions, environment and tests. Doing that now would invent details the user has not selected. See [production roadmap](roadmap.md) and [confirmed scope](../planning/scope.md).
