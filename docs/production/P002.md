# P002: Provider and seller onboarding design

Status: future production planning gate; not part of demo implementation and not authorized execution.

## Dependencies

P001

## Work to specify

Evaluate payment/payout provider availability for the actual business, marketplace account model, seller verification, dispute/refund behavior, webhooks, idempotency guarantees and reconciliation APIs. Prototype in provider test environments.

## Deliverables and exit criteria

Provider capability matrix, credential isolation, sandbox end-to-end charge/refund/payout tests, and a reviewed replacement for the mock adapter.

## Boundary

Do not infer provider capabilities from the demo simulator.

After discovery, break this gate into small implementation tasks with exact provider/API versions, environment and tests. Doing that now would invent details the user has not selected. See [production roadmap](roadmap.md) and [confirmed scope](../planning/scope.md).
