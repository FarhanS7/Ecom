## Goal

Nest-free recovery logic with injected clock/sink/sql: non-enumerating reset
requests, one-use expiring proofs, reset revokes all sessions, verification
activates pending accounts only.

## Acceptance criteria

- [ ] `demo-delivery.ts`: `DemoDeliverySink` (local-dev singleton + fresh
  instances for tests; provider integrations deferred, documented).
- [ ] `recovery.service.ts`: `requestPasswordReset` (generic void; single live
  token per user), `confirmPasswordReset` (consume + rehash + revoke-all in one
  txn), `requestVerification`/`confirmVerification` (pending→active only;
  suspended never lifted), pure `isUsableToken` predicate over an injected now.
- [ ] Contracts: reset/verify DTOs + generic accepted response.
- [ ] Unit tests with fixed clocks: expiry boundary, replay (consumed), wrong
  purpose, suspended untouched — no DB, no sleeps.

## Verification

Backend `build` + `typecheck` + `lint` + unit green. HTTP replay/expiry proof
is T012b (live DB).
