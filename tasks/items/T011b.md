## Goal

Nest session guard + `POST /v1/auth/refresh|logout` + `GET /v1/auth/me`,
browser single-flight refresh helper, and the acceptance race over real HTTP.

## Acceptance criteria

- [ ] Refresh consumes exactly once under row lock; reuse revokes the family;
  expired/revoked fail generic 401; logout revokes + clears cookies.
- [ ] `GET /v1/auth/me` requires a live session (401 otherwise).
- [ ] `apps/web/src/lib/session.ts`: single-flight `refreshSession()` so normal
  browser refresh never races itself (unit-tested with mocked fetch; the
  acceptance "gateway" is this browser-side serialization, not the /api proxy —
  recorded, no proxy changes).
- [ ] Canonical spec `apps/api/tests/integration/refresh.spec.ts`: race two
  refreshes (exactly one 200, no two active descendants), reuse old token
  (family revoked, protected route 401s), expired/revoked sessions fail.
  Needs real DB — honest skips otherwise, live in CI.
- [ ] Contracts: `logoutResponse`; openapi.json regenerated.
