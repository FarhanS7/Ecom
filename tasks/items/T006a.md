# T006a: Error contract and HTTP helpers (pure)

Parent: [T006](T006.md). Created because T006 exceeds one focused session;
keep T006 as the parent ID per its scope rule.

- Module: [platform](../../docs/modules/platform.md)
- Phase: [Foundation](../phases/00-foundation.md)
- Dependencies: [T005](T005.md)
- Branch: `feature/platform/t006-establish-api-and-error-conventions` (shared with T006b)

## Goal

Canonical RFC 7807 error contract (`{type,title,status,detail,instance,code,requestId}`)
with stable codes, plus framework-free HTTP helpers (request-ID handling,
problem-body builder, exception mapper with secret-safe messages).

## Acceptance criteria

- [ ] `packages/contracts/src/errors.ts` defines `errorCodes`, the problem
  schema (superset of the T002 `problemDetails`: adds `code` + `requestId`
  per `docs/architecture/api-contracts.md`), and `api/index.ts` re-exports it
  as the single source (no drift between two schemas).
- [ ] `packages/backend/src/platform/http.ts` exports pure helpers with unit
  tests: valid/missing/invalid request IDs, 4xx mapping, 5xx redaction
  (no stack, no secret values), unknown-route mapping.

## Verification

Backend `build` + `typecheck` + new unit suite green.
