Parent: [T016](T016.md). Created because T016 exceeds one focused session;
keep T016 as the parent ID per its scope rule.

- Module: [stores](../../docs/modules/stores.md)

- Dependencies: [T016a](T016a.md), [T007](T007.md)

## Goal

Public channel endpoint, themed `/stores/{slug}` pages, and proof that unknown/
suspended storefronts stay unavailable while unsafe tokens never render.

## Acceptance criteria

- [ ] `GET /v1/stores/{slug}` (public): active store → `{slug, name, theme}`;
  unknown/suspended/malformed → generic 404. Theme always validated-or-default.
- [ ] Web `stores/[slug]/layout.tsx` (theme CSS variables, server-side) +
  `page.tsx` (store home); unknown slug → Next `notFound()`.
- [ ] `tests/e2e/store-theme.spec.ts` (two slugs differ, unknown 404s;
  browsers absent here → not-run, declared).
- [ ] Backend integration: malicious theme row → endpoint serves default;
  suspended store → 404 (service-level, live in CI).
- [ ] `docs/openapi.json` regenerated (+1 path). No gateway changes (public
  reads go direct server→API like the landing page; browser mutations use the
  gateway per T017).

## Verification

Web `build` + `typecheck`; API gates green; prod curl battery (two slugs,
unknown slug, suspended slug, malicious-theme fallback); bundle clean.
