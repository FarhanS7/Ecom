## Goal and implementation steps

Reuse the owned address book from T091, request a server-issued quote, and build seller-grouped total review, quote-expiry/price-change recovery, stable submission key and status polling. A changed quote requires renewed customer confirmation and a new intended submission key only after a terminal failed attempt.
