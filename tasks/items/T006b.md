## Goal

Wire the T006a helpers into the Nest API: request-ID hook, catch-all problem
filter, `/v1` prefix with unversioned health/docs/metrics excluded, a minimal
validated `GET /v1/ping` probe (versioning + body/query-validation vehicle),
and an OpenAPI generation script validated in tests.

## Acceptance criteria

- [ ] Unknown route → problem JSON (404 NOT_FOUND) with echoed/generated
  request ID in body and `X-Request-Id` header; no stack, no secrets.
- [ ] Invalid input (bad `limit`, malformed `X-Request-Id`) → 422/400 problem
  with stable codes; constraint keys only, never rejected secret values.
- [ ] `scripts/openapi.mjs` generates `docs/openapi.json` from built dist and
  validates title/version/paths; test asserts the served `/docs-json`
  matches the committed file's paths (drift-proof). OpenAPI `openapi` field
  value recorded as measured (3.0 vs 3.1), never faked.
- [ ] Canonical spec: `apps/api/tests/integration/http-contract.spec.ts`
  (package-colocated per repo layout, T003 precedent).
