# T022b: Wire cursors into channel reads and prove the page walk

Parent: [T022](T022.md). Created because T022 exceeds one focused session;
keep T022 as the parent ID per its scope rule.

- Module: [catalog](../../docs/modules/catalog.md)
- Phase: [Catalog and storefront](../phases/02-catalog-storefront.md)
- Dependencies: [T022a](T022a.md)
- Branch: `feature/catalog/t022-add-stable-keyset-pagination` (shared with T022a)

## Goal

Feed the cursor through the read service and public routes, then walk pages
containing duplicate prices and timestamps to prove no duplicate IDs for a
fixed dataset.

## Acceptance criteria

- [ ] `read.service.ts` list accepts `cursor`; fetches `limit + 1` rows,
  returns `limit` and derives `nextCursor` from the last returned tuple
  (null on the final page).
- [ ] `contracts/src/catalog.ts` `channelListQuery` gains a bounded
  `cursor` string; `catalog.controller.ts` passes it through (no new
  paths — the T018 gate is unaffected; openapi regenerated for the
  query param).
- [ ] `packages/backend/tests/integration/pagination.spec.ts` (CI-live,
  honest skips): seed products with DUPLICATE `min_price_cents` and
  DUPLICATE `created_at`; walk every page for each sort with a small
  limit; assert the union of IDs equals the full set once each (no
  duplicates, no gaps, no misses); assert the wrong-channel cursor and a
  changed-filter cursor both fail; assert the mutation semantics in a
  comment (keyset on a fixed set is stable; concurrent writes may shift
  not-yet-visited rows — no cross-request snapshot).

## Verification

Workspace gates green; backend integration exit 0 locally with honest
skips; CI walks the pages live. `t022-context.md` covers both subtasks.
