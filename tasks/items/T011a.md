## Goal

Nest-free session logic: actor resolution (JWT + live family/user state),
single-transaction refresh rotation with row locking, idempotent revocation,
exact-name cookie parsing, and the guard decision contract.

## Acceptance criteria

- [ ] `session.service.ts`: `resolveActor` (null on bad JWT, revoked/expired
  family, suspended user), `rotateRefresh` (row-locked; consumed → revoke;
  expired/invalid → generic invalid; success mints exactly one descendant),
  `revokeFamily` (idempotent), `getSafeUser`.
- [ ] `session.guard.ts`: `Actor` type, `extractCookie`, `decideSession`
  (pure attach-or-deny); Nest adapter lives in the API (T011b).
- [ ] Unit tests with stubbed sql (no DB): reuse→revoked, double-rotation
  impossible, expired→invalid (not revoked), suspended→null actor.

## Verification

Backend `build` + `typecheck` + `lint` + unit green. HTTP race proof is T011b.
