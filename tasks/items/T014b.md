## Goal

One minimal scoped read — `GET /v1/seller/stores/{storeId}/membership` — so the
acceptance retry scenario runs over real HTTP: valid JWT, revoked membership,
no leakage.

## Acceptance criteria

- [ ] Endpoint returns the caller's `{storeId, role, status}` or generic 404
  for non-members AND unknown stores alike (no existence oracle).
- [ ] API spec: Store A owner probes store B (404); membership revoked via SQL,
  retry with the SAME access token → 404 while the token still passes the
  session guard elsewhere (proves scope is re-checked live, never from claims).
- [ ] `docs/openapi.json` regenerated (+1 path).
