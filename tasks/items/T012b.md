## Goal

Nest recovery routes on the existing AuthController surface with generic
(non-oracle) outcomes, verified over real HTTP including expiry and replay.

## Acceptance criteria

- [ ] `POST /v1/auth/password-reset/request` → 202 always (unknown emails
  create nothing); `.../confirm` → 200 + new-password login works + old
  session 401s; replay/second-request-supersede/expired/pre-inserted-expired →
  generic 404 (invalid/expired/consumed indistinguishable).
- [ ] `POST /v1/auth/verify-email/request` (authenticated self) +
  `.../confirm` → pending becomes active and can log in; suspended stays
  suspended; replay → 404.
- [ ] Canonical spec `apps/api/tests/integration/recovery.spec.ts` (real DB or
  honest skip; reads the in-process demo sink for proof tokens).
- [ ] `docs/openapi.json` regenerated (+4 paths).

## Verification

API `build` + `typecheck` + `lint` + `test:integration` green; workspace gates green.
