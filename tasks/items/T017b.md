# T017b: Auth screens, session panel, e2e spec

Parent: [T017](T017.md). Created because T017 exceeds one focused session;
keep T017 as the parent ID per its scope rule.

- Module: [identity](../../docs/modules/identity.md)

- Dependencies: [T017a](T017a.md)
- Branch: `feature/identity/t017-build-account-and-recovery-screens` (shared with T017a)

## Goal

Accessible auth screens wired to the real API through the gateway: register,
login, logout, password reset/confirm, verification confirm, and a session
panel — with announced errors, preserved nonsecret input, and zero browser
persistence of passwords.

## Acceptance criteria

- [ ] `features/auth/auth-forms.tsx` (validated forms; server errors announced
  via role=alert; failed submits keep nonsecret fields), `(auth)/layout.tsx`,
  `features/auth/session-panel.tsx` (me/logout with no redirect loops), and
  pages: `/login`, `/register`, `/forgot-password`, `/reset-password`,
  `/verify-email`.
- [ ] `tests/e2e/account.spec.ts` (register/login/logout/reset journeys +
  no-password-in-storage assertion; browsers absent here → not-run, declared).
- [ ] Storage proof without browsers: bundle+source grep (no localStorage/
  sessionStorage password writes; forms hold secrets in memory only), plus
  `next build` + prod curl (pages render, gateway round-trip live).

## Verification

Web `build` + `typecheck` + `lint` green; curl battery green; grep clean.
