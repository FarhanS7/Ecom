## Goal

Same-origin gateway at `apps/web/src/app/api/[...path]/route.ts` plus the
server helper `apps/web/src/lib/api.ts`: allowlisted paths/headers only,
arbitrary target URLs rejected, no secrets toward the client.

## Acceptance criteria

- [ ] Single-source `ALLOWED_GATEWAY_PATHS` (foundation: `health/live`,
  `health/ready`, `v1/ping`); everything else → 404, never proxied.
- [ ] Only `GET` in T007 scope; only `accept` + `x-request-id` forwarded
  (validated, else server-generated); cookies/authorization NEVER forwarded
  here — cookie sessions arrive with identity work (T010), documented.
- [ ] Path traversal / absolute-URL / protocol-relative targets rejected
  before any fetch; upstream 5s timeout; upstream problem bodies passed
  through with status preserved.
- [ ] `API_BASE_URL` is server-only (no `NEXT_PUBLIC_`); missing → 500 with a
  redacted message naming the variable, never its value.
