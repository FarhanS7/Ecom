## Goal

Extract DESIGN.md §3.1 tokens exactly into `styles/tokens.css`, add the
mobile/reduced-motion exceptions, and provide ONE validated, unit-testable
mapping from the closed T016 `ThemeTokens` contract to the tenant-overridable
CSS variables. No primitives yet (T023b).

## Contract decision (recorded — no shared contract change)

DESIGN.md §2 declares a wider `TenantTheme` (accent/accentContrast/brand,
background-gradient stops, fonts, logo, socials, swatches) than the closed
T016 `themeTokensSchema` ({primary,background,surface,text,muted,accent,
radius}, validated at the boundary). Rather than silently widen the shared
contract, T023 maps ONLY what the validated contract can express and leaves
the DESIGN-only tokens at their ShopScale demo defaults:

| Design token (tenant-overridable) | Source |
| --- | --- |
| `--color-accent` | `--store-accent` |
| `--color-brand` | `--store-primary` |
| `--text-primary` | `--store-text` |
| `--text-secondary` | `--store-muted` |
| `--surface-solid` | `--store-surface` |
| `--bg-page` | `--store-background` |

Locked by DESIGN (radii, spacing, shadows, blur, type scale) never read a
tenant value. The T016 `radius` token keeps driving ONLY the branded
storefront's inner tile corners via `--store-radius` (existing behaviour);
bento card radii stay locked at `--radius-card`.

Extending the shared contract to fonts/gradient stops/swatches is a later
task and requires its own ADR; it is not smuggled into a render change.
