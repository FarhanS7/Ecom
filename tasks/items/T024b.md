## Goal

Server-fetch the public channel reads (T021) into `HomeContent` for the
marketplace home and the branded store home, keeping the shell's observable
contract (health card + gateway probe on `/`) intact, then prove it in e2e.

## Acceptance criteria

- [ ] `features/storefront/load.ts` (server-only): fetch
  `/v1/catalog/marketplace/products` or `/v1/catalog/stores/{slug}/products`,
  validate the body with `channelListResponse`, and return empty content on
  any failure (unreachable API must degrade to reflow, never crash a page).
- [ ] `app/page.tsx` renders `StorefrontHome` for the marketplace (headline
  stays "ShopScale Marketplace" so the T007 shell contract holds) and keeps the
  server-rendered health + gateway probe testids.
- [ ] `app/stores/[slug]/page.tsx` renders `StorefrontHome` with store-scoped
  product links; the store layout stops rendering a second `h1` (the hero owns
  it).
- [ ] `tests/e2e/storefront-home.spec.ts`: browse the marketplace and two
  store homes; assert product/category link targets are the documented routes;
  assert the empty-content store (t016-alpha has no products) shows no product
  cards and no empty shells. CI/bench host only — honest skip where browsers
  are absent.
